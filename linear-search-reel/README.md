# Linear Search مع خوارزمو · ريل تعليمي

ريل عمودي (1080×1920، 30fps، 60 ثانية) بيشرح خوارزمية **البحث الخطّي** مع شخصية تكنو انجاز «خوارزمو».
بدون تعليق صوتي: الشرح كله مكتوب على الشاشة، وتحته موسيقى ومؤثرات أصلية مولّدة بالكود.

| الملف | شو هو |
|---|---|
| `linear-search-khwarizmo.mp4` | الريل النهائي |
| `cover.png` | غلاف مقترح |

## القصة (على إيقاع 112 BPM، وكل مشهد عدد صحيح من الموازير)

| الوقت | المشهد | شو بيصير |
|---|---|---|
| 0:00 | الخطّاف | حيط أرقام، ومربع بحث بينطّ بينها. «كيف الكمبيوتر بيلاقي رقم واحد بين آلاف الأرقام؟» وخوارزمو عم يفكّر |
| 0:04 | العنوان | ضربة: `Linear Search` · «البحث الخطّي»، وخوارزمو بيطلع من تحت: «أنا خوارزمو 👋» |
| 0:09 | المصفوفة | 7 صناديق مسكّرة بتنزل وحدة وحدة (كل صندوق بنغمة)، وبطاقة «المطلوب: 5» |
| 0:15 | البحث | خوارزمو بينطّ على أول صندوق والكاميرا بتقرّب. بيفتح، بيقارن (`7 ≠ 5`)، بينطّ للي بعده… لحد الصندوق 4: انفجار وكونفيتي «لقيناه!» |
| 0:28 | القاعدة | 3 بطاقات: ابدأ من أول عنصر · قارنه بالمطلوب · هو؟ وقّف، مش هو؟ كمّل |
| 0:34 | الكود | 5 سطور Python عم تنكتب، وبعدين بتشتغل سطر سطر مع المصفوفة |
| 0:43 | السرعة | أحسن حالة `O(1)` · أسوأ حالة `O(n)` · مليون عنصر = مليون مقارنة |
| 0:51 | الختام | إيمتى منستعملها؟ ثم تشويق `Binary Search` بالريل الجاي، وبطاقة «تابع تكنو انجاز» |

## كيف انعمل

```
timeline.json     الإيقاع، أطوال المشاهد بالـ beats، المصفوفة والرقم المطلوب
build_assets.py   قصّ وضعيات خوارزمو من ورقة الشخصية (isnet + قناع ألوان لقرون الاستشعار) → assets/k/*.png
reel.html + js/   engine.js (كاميرا، نص عربي، جزيئات، خلفية، توهّج وتشويش لوني) · scenes.js (المشاهد الثمانية + جدول الأصوات)
music.py          الموسيقى والمؤثرات من نفس جدول الأحداث اللي بتمشي عليه الصورة
render.mjs        التصيير بـ 4 عمّال + ffmpeg
```

بمشهد البحث، الصوت هو الخوارزمية نفسها: كل صندوق بينفتح بنغمة أعلى من اللي قبلها، وكل «مش هو» بـ bonk ناعم،
وعند «لقيناه» بتدخل الفرقة كلها على كورد ماجور، مع لحظة صمت صغيرة قبلها.

## التشغيل

```bash
pip install numpy scipy opencv-python-headless onnxruntime
ln -sfn "$(npm root -g)" node_modules       # playwright مثبّت global
node render.mjs                              # الريل كامل
STILLS=16.1,22.8,57.5 node render.mjs        # لقطات للمراجعة بـ build/stills
AUDIO_ONLY=1 node render.mjs                 # الموسيقى لحالها: build/soundtrack.wav
python3 build_assets.py                      # إعادة قصّ الشخصية (بيحتاج build/isnet-general-use.onnx، الرابط بالسكريبت)
```

**لتغيّر المثال:** عدّل `arr` و`target` بـ `timeline.json`. الرقم المطلوب لازم يضل بالخانة 4، لأن توقيت المشهد والنصوص مبنيين عليها.
