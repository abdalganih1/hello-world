# Linear Search مع خوارزمو · ريل تعليمي

ريل عمودي (1080×1920، 30fps، 52 ثانية) بيشرح خوارزمية **البحث الخطّي**.
**بالصوت:** خوارزمو بيشرح بالصوت المتفق عليه (ElevenLabs `eleven_v3`، النص العادي مع تعليمة لهجة شامية دمشقية، صوت صاحب الحساب = الملف 10، مع القراءات اللي اختارها).
الجمل التلاتة الأولى انولّدلها 4 قراءات، و`tools/auto_voice.py` اختار الأقرب للسوري (موديل لهجات + فحص Whisper).
تحت الكلام: خلفية هادية وأصوات خفيفة (`tools/mix.py`). نسخة الموسيقى بدون صوت: `tools/score.py` بـ `render.mjs`.
مشهد المقارنة مسرّع: السكتة بين الرقم و«لأ» بتنقصّ لحد 0.18 ثانية (`squeeze` بـ `voice/script.json`).

## كيف انعمل

```
voice/script.json      نص خوارزمو (text, hl = كلمات تركواز, take = محاولة جديدة, pause)
tools/build_voice.py   صوت كل جملة (مع cache بـ audio/cache) ← build/voice.wav + voice/timeline.json
                       (بداية كل جملة وكل مقطع فيها: الصورة بتمشي عليهن، مثلاً «✗» بلحظة «لأ»)
tools/mix.py           الصوت + خلفية موسيقية هادية جداً تحت الكلام + أصوات خفيفة للحركات ← -14 LUFS
reel.html + js/        engine.js (الطابع الفاتح، النص العربي، خوارزمو) · scenes.js (المشاهد)
build_assets.py        قصّ وضعيات خوارزمو من ورقة الشخصية ← assets/k/*.png
render.mjs             التصيير + ffmpeg
```

## التشغيل

```bash
pip install numpy scipy opencv-python-headless
ln -sfn "$(npm root -g)" node_modules
export ELEVENLABS_API_KEY=... ELEVENLABS_VOICE_ID=...
python3 tools/build_voice.py        # بس الجمل الجديدة أو المعدّلة بتنطلب
node render.mjs                     # الريل كامل (حوالي دقيقتين)
STILLS=1.4,21.4,30.3 node render.mjs
```

**جملة انلفظت غلط؟** زيد `take` لهالجملة بـ `voice/script.json`، أو حط `tts` بالنطق اللي بدك ياه، وشغّل الأمرين.

**النبرة:** أول جملة بتعليمة `[incredulous, disapproving]` (استنكار)، والباقي `[energetic, enthusiastic, friendly]`، فوق تعليمة اللهجة الشامية.
لكل جملة 4 قراءات، والأداة اختارت الأقرب للسوري. وبـ 3 جمل اخترت يدوياً قراءة كلماتها كاملة حسب Whisper (موثّقة بـ `voice/takes.json`).
**العبارات:** السطر بينكسر عند نهاية الجملة أو الفاصلة (`phraseWrap` بـ `js/engine.js`)، والسطر التاني بيطلع لما ينحكى.
وفيك تحدد مكان الكسر بإيدك بـ `|` بحقل `caption`.
