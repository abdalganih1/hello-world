# الدارة ولوحة التجارب · الحلقة 05 · أردوينو من الصفر · منصة مسار

فيديو تعليمي أفقي (1920×1080، 30fps)، مدته حوالي 4:49، ومبني بنفس محرك الحلقات السابقة.
حسب خطة الدورة (`../masar-course-plan.md`): المستوى 1، أول LED خارجي على Breadboard.

**الدقة الإلكترونية:**
- **لوحة التجارب:** 30 عمود، وكل عمود فيه 5 ثقوب موصولة (a–e وf–j)، ومجرى بالنص، وخطّين + و− فوق وتحت.
- **الدارة:** القطب 13 ← سلك للعمود 12 ← مقاوم 220Ω (أحمر، أحمر، بني، ذهبي) من العمود 12 للعمود 16 ← الطرف الطويل للضوء بالعمود 16، والقصير بالعمود 17 ← سلك للخط الأزرق − ← GND.
- **الحساب:** (5V − 2V) ÷ 15mA = 200Ω، والأقرب بالسوق 220Ω، فالتيار ≈ 13.6mA، وهو أقل من حد الضوء (20mA).
- **الأقطاب بلوحة الأردوينو:** GND و13 و12 و8 مرسومة بمكانها الحقيقي على الشريط العلوي.

**التوليد:**

```bash
export VIBI_API_KEY=...
THREADS=5 python3 tools/vibi_voice.py --field fusha --takes 1
TEMPO=1.1 VOICE_SRC=fusha python3 tools/build_audio.py && python3 tools/music.py
ln -sfn /opt/node22/lib/node_modules node_modules && node render.mjs
```
