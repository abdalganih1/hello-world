# الصوت · الحلقة 11 · أردوينو من الصفر · منصة مسار

فيديو تعليمي أفقي (1920×1080، 30fps)، مدته حوالي 3:35، ومبني بنفس محرك الحلقات السابقة.
حسب خطة الدورة (`../masar-course-plan.md`): آخر حلقة بالمستوى 2 (بالخطة رقمها 10). الفكرة الجوهرية: «الصوت اهتزاز بتردد». والتجربة: لحن قصير.

| الملف | شو هو |
|---|---|
| `masar-arduino-ep11.mp4` | الفيديو النهائي |
| `script_and_scenes.md` | السكريبت الصوتي كامل مع التوقيت (🔊 = نغمات مسموعة) |
| `masar-arduino-ep11.srt` | الترجمة المتزامنة |
| `publishing.md` | 3 عناوين، والوصف، والفصول |

**الأنغام مسموعة بالفيديو:**
- بالسكريبت: كل جملة إلها `gap` (وقفة بعد الجملة) و`tones` (الأنغام).
- `tools/build_audio.py` بيحطّهم على الخط الزمني.
- `tools/music.py` بيولّد صوت البازر: موجة مربعة فيها الهارمونيات الفردية لحد 7kHz، والموسيقى بتوطى تحت الأنغام متل ما بتوطى تحت الصوت.
- الصورة بتقرأ نفس الأوقات (`toneAt`)، فالمفتاح والموجة والبازر بيتحركوا مع النغمة بالظبط.
- فحصت الترددات بالـ FFT: 262 و330 و392 و440 و523 و659 و2300 Hz كلها بمكانها.

**الترددات:** Do 262، Re 294، Mi 330، Fa 349، Sol 392، La 440، Si 494، Do 523. اللحن من تأليفنا.

**التوليد:**
```bash
export VIBI_API_KEY=...
THREADS=5 python3 tools/vibi_voice.py --field fusha --takes 1
TEMPO=1.1 VOICE_SRC=fusha python3 tools/build_audio.py && python3 tools/music.py
ln -sfn /opt/node22/lib/node_modules node_modules && node render.mjs
```
