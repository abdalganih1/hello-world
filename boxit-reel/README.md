# BOXIT — ريل إعلاني Motion Graphics

`boxit-reel.mp4` · 1080×1920 · 30fps · 12 ث · ستيريو · بدون صوت متكلم · ألوان: `#F05A28` `#266332` `#FFFFFF` بس.

| الوقت | المشهد |
|---|---|
| 0–2 | خلفية برتقالية، «بدك تطلب؟» بتدخل من اليمين لليسار من ورا قناع، ونقطة خضرا صغيرة تحتها (Whoosh) |
| 2–4 | «اختار اللي بدك ياه.» وبطاقات التطبيق الحقيقية (المطاعم، الكترونيات، حلويات شرقية-غربية، بن و ضيافة) بنفس ترتيبها المتناوب، ونقطة خضرا بتختار «المطاعم» (UI Clicks) |
| 4–6 | البطاقة بتكبر لصفحة بيضا، وبتطلع شاشة المنتج من التطبيق (موزريلا تشيز برغر لحم · سيتي برغر · 650 ل.س · أضف إلى السلة)، ولمسة على الزر، وبعدين «اطلب.» (Tap) |
| 6–8 | زر السلة بينضغط لخط حركة برتقالي بيطلع يسار وبيرجع من اليمين، وبيوقف عند طرد بسيط مع خطوط السرعة تبع الشعار، و«ونحنا منوصلها.» (Whoosh + Thud) |
| 8–10 | الأخضر بيطلع من الطرد ويعبّي الشاشة، والشعار الأصلي بـ Fade + Scale |
| 10–12 | «اختار.» «اطلب.» «استلم.» ورا بعض، بيضلّ «استلم.»، وبيطلع CTA «اطلب من التطبيق» مع خط برتقالي صغير |

## كيف انعمل
- `build_assets.py`: الشعار الأصلي بعد ما تشالت الخلفية البيضا بس (ما انرسم من جديد ولا تغيّر شكله). وصور البطاقات مقصوصة من لقطات التطبيق نفسها ومحوّلة لدرجات الأخضر والأبيض حتى نضل بالألوان الثلاثة.
- `reel.html`: مشهد Canvas2D حتمي (`seek(t)`). خط Alexandria الهندسي (800/900).
- `music.py`: موسيقى أصلية مولّدة بالكود (120 BPM، كل مشهد بار واحد) ومعها مؤثرات من `timeline.json`.
- `render.mjs`: Chromium headless بيرسم الفريمات، وffmpeg بيدمج الصورة مع الصوت.

```bash
pip install numpy scipy pillow imageio-ffmpeg
ln -sfn /opt/node22/lib/node_modules node_modules
python3 build_assets.py
FFMPEG=$(python3 -c "import imageio_ffmpeg as i; print(i.get_ffmpeg_exe())") node render.mjs
STILLS=1,3,5,7,9,11.9 node render.mjs     # لقطات سريعة
```
