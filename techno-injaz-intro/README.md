`techno-injaz-intro.mp4`: فيلم قصير لريلز إنستغرام، عمودي 1080×1920 (9:16)، مدته 20.5 ثانية بـ 30 إطار بالثانية، وصوته ستيريو. `cover.png` صورة الغلاف.

## كيف انعمل

- **الصورة (`intro.html`):**
  - الرسم بـ Canvas 2D فوق خلفيات مرسومة بشيدرات WebGL2: سماء الغروب، الغيوم، السديم والنجوم، وكرة أرضية ثلاثية الأبعاد. الأرض فيها قارات وغيوم وغلاف جوي وأضواء مدن.
  - بعدها مرحلة معالجة بألوان HDR: توهّج (bloom)، ضبابية شعاعية، موجات صدمة، سراب حرارة، تشويش لوني، وهج عدسة، أشرطة سينمائية، وحبيبات فيلم.
- **الشعار (`build_assets.py`):** مقصوص من الصورة الأصلية لثلاث طبقات مع حدودها الهندسية. هاد اللي سمح برسم الخطوط الهولوغرامية بالظبط على شكل الشعار.
- **الصوت (`music.py`):**
  - الموسيقى والمؤثرات كلها مولّدة بالكود، بلا أي عينات ولا حقوق نشر.
  - فيها: لوفاي بالغرفة بينتهي بـ tape stop، وشحن ونبض قلب، وضربة إشعال، وموسيقى ملحمية مع كورال، وصمت عند قطع المحركات، وكورد شروق، ولحن بيتكوّن من كتابة Hello world.
- **الأزمنة كلها بـ `timeline.json`.** الصورة والصوت بيقروا منه، فأي تعديل بيضل متزامن.

## التوليد

```
FFMPEG=<مسار ffmpeg> node render.mjs              # الفيديو كامل (4 عمّال بالتوازي)
STILLS=3.3,10.5,18 node render.mjs                # لقطات فقط للمراجعة
AUDIO_ONLY=1 node render.mjs                       # الصوت فقط
```

بحاجة: Node مع playwright، وpython3 مع numpy وscipy (وopencv لـ `build_assets.py`).
