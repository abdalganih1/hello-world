# Merge Sort مع خوارزمو · ريل تعليمي (الرابع بالسلسلة)

ريل عمودي (1080×1920، 30fps، 58.6 ثانية)، بنفس محرك ريلات Linear Search و Binary Search و Bubble Sort.
الصوت جورج حسب مهارة `george-voice`: فصحى مبسطة، والمصطلحات الإنكليزية بحروفها. السكريبت الكامل بـ `voice_script.md`.

**الحقائق:**
- **مليون رقم:** Bubble Sort بيعمل n(n-1)/2 ≈ 5×10¹¹ مقارنة، و Merge Sort بيعمل تقريباً n·log₂n ≈ 2×10⁷ مقارنة، يعني أقل بـ 25,000 مرة.
- **بثانية لكل مقارنة:** حوالي 15,855 سنة، مقابل حوالي 231 يوم، يعني أقل من 8 أشهر.
- **قصة أوباما (Google، 2007):** قال «the bubble sort would be the wrong way to go».
