# Hexapod Mochi: فيديو تجميع ومشي

`hexapod-mochi.mp4`: ‏1080×1920، ‏30fps، ‏31 ثانية، ستيريو، بدون صوت متكلم.

الروبوت هو **Hexapod Mochi** من [rookidroid/hexapod](https://github.com/rookidroid/hexapod) (رخصة GPL-3.0)، وهو نفسه موديل MakerWorld رقم 2399303.
كل قطعة بالفيديو هي ملف STL الأصلي من المستودع. ما في ملف تجميع جاهز، فانركّبت القطع بالكود عن طريق مطابقة ثقوبها الحقيقية:
- ثقوب البيرينغ على أطراف الجسم على نصف قطر 81.8 مم، وهي نفس نقاط تركيب الأرجل بالـ firmware
- شبابيك السيرفو
- ثقوب الهورن والمسامير

والحركة من أبعاد `mochi.json`: ‏coxa ‏36، ‏femur ‏43.6، ‏tibia ‏85.22 مم.

عدّاد القطع `PARTS 000/135` بيعدّ كل قطعة لحظة ما تركب. وكل قطعة إلها صوت طقّة بنفس الفريم.

## الملفات
- `robot.js`: تركيب الروبوت من الـ STL، مع إحداثيات كل قطعة و IK للأرجل
- `reel.html`: المشهد (Three.js، إضاءة، أرضية، شرارات، bloom)، والجدول الزمني للتجميع، ومشية tripod، والكاميرا، والنصوص العربية
- `music.py`: موسيقى أصلية ومؤثرات مولّدة بالكود. الأحداث بتنحسب من نفس جدول التجميع والمشي
- `build_meshes.py`: بيخفف المثلثات بالـ STL حتى يصير التوليد أسرع، وبيضل الفرق عن القطعة الأصلية أقل من 0.1 مم
- `test.html` / `test.mjs`: معاينة سريعة للروبوت المركّب من أي زاوية

## التوليد
```bash
pip install numpy scipy trimesh fast_simplification imageio-ffmpeg
ln -sfn /opt/node22/lib/node_modules node_modules
python3 build_meshes.py
FFMPEG=$(python3 -c "import imageio_ffmpeg as i; print(i.get_ffmpeg_exe())") node render.mjs   # ~2 ث/فريم بـ 4 عمّال
STILLS=3,10,22,29 node render.mjs     # لقطات سريعة
```
