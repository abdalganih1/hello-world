# صوت جورج: التعليق الصوتي المعتمد

هاد هو الإعداد يلي ثبّته المالك بعد ريل Bubble Sort، وقال عنه: «النص والنطق ممتاز». لا تغيّر فيه شي إلا إذا طلب.
وكل محاولات اللهجة الشامية قبله فشلت، مهما جرّبنا تشكيل أو كتابة صوتية أو موديل لهجات. فما في داعي ترجع تجرّبها.

## 1. الإعداد الثابت

| البند | القيمة |
|---|---|
| المزوّد | vibi.pro (غلاف لـ ElevenLabs): `https://vibi.pro` |
| الصوت | **George**: `JBFqnCBsd6RMkjVDRZzb` (ElevenLabs premade: Warm, Captivating Storyteller) |
| الموديل | `eleven_v4`، و `language_code: "ar"`، و `provider: "elevenlabs"` |
| الإعدادات | `stability 0.5`، و `similarity_boost 0.75`، و `speed 1.0` |
| المفتاح | `VIBI_API_KEY` من البيئة، أو أول سطر بـ `~/.vibi_key`. **ممنوع ينكتب بأي ملف بالمستودع** |
| السرعة بالمونتاج | `atempo 1.12`، وكل وقفة جوّا الجملة بتنقص لـ 0.22 ثانية، والمدة النهائية أقل من 60 ثانية |

**الطلب غير متزامن.** الـ POST بيرجّع `202` ومعه `id`. بعدها اسأل `GET /v1/history/{id}` كل ثانيتين لحد ما توصل
`completed`، وبعدين نزّل `result.audio_url` **فوراً**، لأن الروابط بتنحذف بعد فترة.

**الفخاخ:**
- الهيدر `xi-api-key` وليس `Bearer`.
- لازم User-Agent متصفح، لأن Cloudflare بترجّع `403 / 1010` لبايثون العادي.
- الـ voice_id بالـ URL وليس بالـ JSON.
- النص UTF-8.

كل هاد محلول بـ `scripts/vibi_tts.py`.

**جورج ثابت (deterministic):** نفس النص بيعطي نفس الصوت بالزبط. لهيك لا تولّد «take» تاني من نفس الجملة.
إذا بدك نتيجة مختلفة، **غيّر الكتابة**: كلمة تانية أو صيغة تانية.

## 2. كتابة السكريبت الصوتي (أهم جزء)

القواعد الكاملة مع أمثلة بـ `references/writing_rules.md`، وهي الخلاصة:

1. **فصحى مبسطة، مو فصحى رسمية:** كلمات يومية، متل «عِنْدَنا» بدل «لَدَيْنا»، و«غَيْر مُرَتَّبَة» بدل «مُبَعْثَرَة»،
   و«هَيّا نَفْهَم» بدل «دَعونا نَفْهَمُها مَعًا»، و«نَنْتَهي» بدل «لَانْتَهَيْنا».
2. **تركيب الجملة فصحى من الأول، مو عامية مترجمة:** متل «إِنْ كُنْت لا تَعْرِف» و«وَإِلّا فَانْتَقِل» و«إِذا كانَت القائِمَة مُرَتَّبَة، فَهُناك…».
   الجدول بالقسم 7 بـ `references/writing_rules.md`.
3. **تشكيل كامل على كل الحروف، بس بدون حركات إعراب بآخر الكلمة:**
   - اكتب «سَبْعَة أَرْقام» وليس «سَبْعَةُ أَرْقامٍ»، و«مِلْيون رَقْم» وليس «مِلْيونَ رَقْمٍ».
   - التنوين ما بينحط إلا لما يكون مسموع وطبيعي، متل «رَئيسًا».
4. **القاف قاف:** ممنوع الهمزة الشامية (رَأِم، مْآرَنِة). المالك رجّعها قاف.
5. **المصطلح الإنكليزي بيتكتب بالحروف الإنكليزية**، لحتى ينقرأ إنكليزي: `Google`، `Bubble Sort`، `Reel`، `Big O of n squared`.
   - **لا تلزق «بالـ» أو «الـ» بكلمة إنكليزية بعدها**، لأنها بتتخربط («بالـ Bubble Sort» طلعت «بالبوبل صوت»).
     استعمل كلمة عربية بالنص: «بِطَريقَة Bubble Sort» أو «خوارزمية Bubble Sort».
   - «في الـ Reel القادِم» مشيت لأن «الـ» هون مفصولة.
   - **الرموز بتنقرأ متل ما بيقولها الإنكليزي:** O(n²) بتنكتب «Big O of n squared»، و O(n log n) بتنكتب «Big O of n log n».
6. **ابعت السكريبت للمالك قبل التوليد** إذا طلب يشوفه، بجدول (رقم، الجملة كما رح يقرأها الصوت)،
   ووضّح كل مصطلح إنكليزي وكيف رح ينقرأ.
7. **جملة قصيرة لكل فكرة:** وحدة لكل مشهد أو حدث، لحتى الصورة تمشي مع الصوت.

## 3. التشغيل

```bash
export VIBI_API_KEY=...            # من المالك، لا تحطه بملف بالمستودع
S=.claude/skills/george-voice/scripts
python3 $S/george_voice.py voice/script.json build/voice      # بيولّد ويفحص ويختار ← build/voice/takes.json
python3 $S/assemble.py     voice/script.json build/voice      # ← build/voice/voice.wav + timeline.json
python3 $S/vibi_tts.py --balance                              # الرصيد (1 رصيد لكل حرف، مع التشكيل)
```

**شكل `script.json`:**

```json
{"lines": [{"id": "hook", "scene": "hook", "say": "أوباما، قَبْل أَنْ يُصْبِح رَئيسًا، سُئِل في Google: ..."},
           {"id": "answer", "scene": "answer", "say": ["صيغة 1", "صيغة 2"], "pause": 0.8}]}
```

- **`say`:** نص، أو قائمة صيغ للجملة الوحدة. السكربت بيختار الصيغة يلي سمعها Whisper أقرب للنص.
- **`pause`:** سكوت إضافي بعد الجملة، مفيد لما الصورة بدها وقت متل جولة ترتيب.
- **`dur`:** سطر سكوت بس.
- **المثال الكامل:** `examples/bubble_sort_script.json`، وهو السكريبت المعتمد لريل Bubble Sort.

**الفحص:**
- Whisper بيكشف الكلمات الناقصة أو الزايدة أو المخربطة، بس **ما بيقدر يحكم على اللهجة أو جمال الإلقاء**.
- الجمل يلي بيطلع فيها `sim < 0.9` بيتعلّم عليها «listen». جرّب إلها صيغة تانية، وقول للمالك بالزبط شو الكلمة المشكوك فيها.
- Whisper بالعربي بيكتب المصطلح الإنكليزي أحياناً بحروف عربية، متل «جوجل» و«الريل». هاد مو خطأ، بس اذكره للمالك ليسمعه.
- **إنذار «listen» متوقّع بالحالات هي:** الأرقام، لأن Whisper بيكتب «16» بدل «سِتَّة عَشَر»، والمصطلحات يلي بيكتبها بحروف عربية، متل «بيغ أو».
  بالريل المعتمد طلع الإنذار بـ 4 جمل، وكلهن كانوا سليمين.

## 4. ربط الصوت بالصورة

- **`timeline.json`** فيه لكل جملة: `t0` و`t1`، و`segs` (بداية كل مقطع مسموع)، و`say` (النص المنطوق بدون تشكيل).
  - **وقّت الحركة على الكلمة المنطوقة:** دوّر عليها بـ `say`، مو بالنص المكتوب على الشاشة.
    مثال: `AT(i, "Big", "O(n²)")` بيجرّب أول كلمة لاقاها.
  - المرجع: `AT()` بـ `bubble-sort-reel/js/engine.js`.
- **العناوين على الشاشة** بتكون **بنفس لغة الصوت**: فصحى مبسطة **بدون تشكيل** وبدون شدّة.
  - لازم تحكي نفس الكلام، متل «عندنا 7 أرقام غير مرتبة» و«أوباما كان على حق ✓».
  - إذا العنوان فيه مصطلح إنكليزي، لا تحط «!» جنبه، لأن اتجاه النص بيقلبها. اكتب «ليس بطريقة Bubble Sort 😂».
- **الموسيقى تحت الصوت:** هادية ومنخفضة وقت الكلام (`tools/mix.py` بالريلات)، والمستوى النهائي −14 LUFS.
