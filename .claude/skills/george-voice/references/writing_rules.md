# قواعد كتابة السكريبت الصوتي لجورج

هالقواعد طلعت من ريل Bubble Sort، بعد كذا جولة تعديل مع المالك.

## 1. الطريق يلي مشينا فيه (لا ترجع للمحاولات الفاشلة)

| المحاولة | النتيجة |
|---|---|
| صوت المالك (eleven_v3) + تعليمة «Syrian Damascene accent» + نص عادي | أقرب شي للشامي، بس القاف والكلمات ما كانت مزبوطة |
| نفس الصوت + تشكيل خفيف + كلمات شامية (الزغير، اسمو، معو) | تحسّن بسيط، وكلمات لسا غلط |
| جورج + تشكيل كامل + همزة بدل القاف (رَأِم، مْآرَنِة) | جورج مو صوت سوري، وموديل اللهجات عطى تقييم سالب لكل الجمل |
| جورج + فصحى رسمية بكامل الإعراب (سَبْعَةُ أَرْقامٍ) | النطق نظيف بس الإلقاء متكلّف ورسمي، والمدة 64 ثانية |
| **جورج + فصحى مبسطة، تشكيل كامل بدون إعراب بالآخر، مصطلحات إنكليزية بحروفها** | **«النص والنطق ممتاز»: هاد المعتمد** |

## 2. فصحى مبسطة: بدّل هيك

| بدل (رسمي أو ثقيل) | اكتب (مبسّط) |
|---|---|
| لَدَيْنا | عِنْدَنا |
| مُبَعْثَرَة | غَيْر مُرَتَّبَة |
| دَعونا نَفْهَمُها مَعًا | هَيّا نَفْهَم |
| مُتَجاوِرَيْن | بِجانِب بَعْض |
| نُبَدِّلُهُما | نُبَدِّل مَكانَهُما |
| ثُمَّ نُعيدُ | وَنُعيد |
| تُصْبِحَ | تَصير |
| هذا هُوَ | هذا اسْمُه |
| لَوْ كانَتْ … لَانْتَهَيْنا | لَوْ … نَنْتَهي |
| تَحْتاجُ إِلى | تَحْتاج |
| فَما هِيَ الطَّريقَةُ | طَيِّب، ما الطَّريقَة |
| لِذلِكَ | لِهذا |

## 3. التشكيل

- **شكّل كل حرف بالكلمة**، ومعه الشدّة، بس **آخر حرف خلّيه ساكن أو بدون حركة**:
  - «تُرَتِّب» مو «تُرَتِّبُ».
  - «رَقْم» مو «رَقْمٍ».
  - «القادِم» مو «القادِمِ».
- **التنوين بالنصب المسموع بس**، متل «رَئيسًا».
- **ألف الوصل والمدّ** متل ما هنن: «اسْمُه»، «آخِر».
- **ما في تشكيل على الكلمات الإنكليزية.**

## 4. المصطلحات الإنكليزية

| المكتوب على الشاشة | السكريبت الصوتي |
|---|---|
| Google | `Google` |
| Bubble Sort | `بِطَريقَة Bubble Sort` / `تَرْتيب الفُقّاعَة، Bubble Sort` |
| O(n²) | `Big O of n squared` |
| O(n log n) | `Big O of n log n` |
| O(n) / O(log n) | `Big O of n` / `Big O of log n` |
| Merge Sort / Quick Sort / Binary Search | `Merge Sort` / `Quick Sort` / `Binary Search` |
| Reel | `في الـ Reel القادِم` |

**ممنوع:** «بالـ Bubble Sort»، و«ببابل سورت»، و«الـ Bubble Sort» بعد «ليس».
جرّبنا 4 صيغ، وانسمعوا «بالبوبل صوت» و«ببابل سوارد» و«البابل صوت». الصيغة يلي مشيت: **«لَيْس بِطَريقَة Bubble Sort!»**.

## 5. الأرقام

- **اكتب الرقم كلمات مشكّلة:** «سِتَّة عَشَر أَلْف سَنَة»، و«واحِد وَعِشْرين مُقارَنَة»، و«نِصْف تْرِلْيون».
- **الرقم بالخانات** بيتكتب على الشاشة بس، متل 16,000 و 21.

## 6. السكريبت المعتمد (ريل Bubble Sort، 59 ثانية)

موجود كامل بـ `examples/bubble_sort_script.json`، وهي نماذج منه:

- أوباما، قَبْل أَنْ يُصْبِح رَئيسًا، سُئِل في Google: كَيْف تُرَتِّب مِلْيون رَقْم؟
- فَأَجاب: بِالتَّأْكيد لَيْس بِطَريقَة Bubble Sort!
- الفِكْرَة: نُقارِن كُلّ رَقْمَيْن بِجانِب بَعْض، وَإِذا كان الأَوَّل أَكْبَر، نُبَدِّل مَكانَهُما.
- وَهذا ما نُسَمّيه: Big O of n squared.
- طَيِّب، ما الطَّريقَة الصَّحيحَة؟ في الـ Reel القادِم.

## 7. لا تترجم العامية كلمة بكلمة (درس ريل Linear Search)

المالك حسّ إن الصوت عم يقرأ «عامية مكتوبة بحروف فصحى». السبب كان **تركيب الجملة**، مو الكلمات.
لهيك اكتب كل جملة كإنها انكتبت بالفصحى من الأول:

| تركيب عامي (غلط) | فصحى مبسطة سليمة |
|---|---|
| إذا لا تعرف هذه الخوارزمية | إِنْ كُنْت لا تَعْرِف هذِه الخَوارِزْمِيَّة |
| إذا وجدته توقف، وإذا لا، أكمل | إِنْ وَجَدْتَه فَتَوَقَّف، وَإِلّا فَانْتَقِل إِلى العُنْصُر التّالي |
| إذا القائمة مرتبة، هناك… | إِذا كانَت القائِمَة مُرَتَّبَة، فَهُناك… |
| إذا الرقم في الآخر، يجب أن تمر على الكل | إِذا كان الرَّقْم في النِّهايَة، فَسَتَمُرّ عَلى الكُلّ |
| هذه اسمها خوارزمية… | تُسَمّى هذِه الخَوارِزْمِيَّة: … |
| مئة عنصر يعني مئة مقارنة | مِئَة عُنْصُر تَعْني مِئَة مُقارَنَة |
| من الأول للآخر / واحدة واحدة | مِن الأَوَّل إِلى الآخِر / واحِدَة تِلْو الأُخْرى |

**وكمان:**
- جواب الشرط بياخد «فَـ»: «فَلا تَقُل»، و«فَسَتَمُرّ»، و«فَهُناك».
- **ياء النسبة بالآخر بدون شدّة:** «الخَطّي» مو «الخَطِّيّ»، و«مَخْفي» مو «مَخْفِيّ».
- **«تِسْعَة» لحالها انقرأت «تسع».** «تِسْعَه» بالهاء انقرأت صح. إذا رقم انقرأ ناقص بآخره، جرّب الهاء.
- **«ما نُسَمّيه:» قبل كلمة إنكليزية انقرأت «نسمي».** «وَهذا ما يُسَمّى: Big O of n» انقرأت كاملة.
- **راجع العنوان على الشاشة بنفس القاعدة:** «إن كنت لا تعرف…»، و«إذا كان في النهاية… ستمر على الكل».
