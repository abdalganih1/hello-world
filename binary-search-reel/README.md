# Binary Search مع خوارزمو · ريل تعليمي

ريل عمودي (1080×1920، 30fps، 58.6 ثانية)، والتاني بسلسلة الخوارزميات بعد `linear-search-reel`.
فيه نفس الطابع ونفس المحرك: خلفية فاتحة بألوان البوستات، ونظام عناوين ثابت، وخوارزمو عاليسار (بيمشي وبيتفرّج وبينطّ وبيرفع إبهامه).
الصوت: الملف 10 (صوت صاحب الحساب، `eleven_v3`، تعليمة لهجة شامية)، بنبرة متحمّسة. كل جملة إلها 4 قراءات، و`tools/auto_voice.py` اختار الأقرب للسوري.

| الوقت | المشهد | الصورة |
|---|---|---|
| 0:00 | الهوك: «من بين 8 مليار إنسان… بلاقيك بـ 33 سؤال بس 🤯» | كرة أرضية من نقاط بتنقص بالنص مع كل سؤال، لحد نقطة وحدة: «هاد إنت 👆» |
| 0:05 | «السر؟ ما منفتش… منقسم ✂️» | قائمة طويلة بتنقص بالنص مرتين |
| 0:08 | «وين الرقم 51؟» | 11 بطاقة مرتّبة، وخوارزمو بيدخل ماشي |
| 0:13 | 4 خطوات: 37 أصغر، 63 أكبر، 45 أصغر، 51 لقيناه | قوس النطاق بيضيق، والنص اللي بينرمى بيطيح ويختفي |
| 0:28 | «البحث الثنائي» | Binary Search، وإبهام خوارزمو لفوق |
| 0:30 | الشرط: القائمة مرتّبة · بكل خطوة منرمي النص | مرتّبة ✓ مقابل عشوائية ✗، وشريط بينقص بالنص |
| 0:37 | مليون ← 20 خطوة · الخطي: مليون 🐢 · `O(log n)` | عدّاد بينقص للنص، ومقارنة أشرطة، ومنحنى لوغاريتمي مقابل خط مستقيم |
| 0:48 | «ولهيك: 8 مليار ← 33 سؤال» | رجعة للكرة الأرضية |
| 0:53 | «بس كيف منرتّب القائمة؟» ← «شو هي؟ بالريل الجاي 👀» | أرقام عشوائية، وبعدين بطاقة مقفولة ومغبّشة فيها `Sorting` |

التشغيل متل `linear-search-reel`: `python3 tools/auto_voice.py --auto --agreed && python3 tools/build_voice.py && node render.mjs`.
وضعيات خوارزمو منسوخة من `linear-search-reel/assets/k` (عليها الشعار ومنظّفة).
